# Aligned Raster Algebra

离线栅格地图代数工具，仅依赖 Python 3.12+ 标准库。读取 JSON 任务，
将整数坐标定位的矩形网格对齐后逐格计算表达式，并报告缺失与异常数据。

## 用法

```
python -m raster_algebra INPUT.json OUTPUT.json
```

任务非法时进程以非零码退出，且不会创建或修改结果文件
（结果文件先写入临时文件，再原子替换）。

## 任务格式

```json
{
  "grids": {
    "a": {"x": 0, "y": 0, "cell": 2, "data": [[1, null], [3, 40]]},
    "b": {"x": 2, "y": -2, "cell": 2, "data": [[10], [20]]}
  },
  "expression": "coalesce(a / b, a, -1)",
  "extent": "union"
}
```

- 每个网格有唯一名；`x`/`y` 为左上角整数坐标（支持负数），列向右、行向下。
- `cell` 为正整数格宽；所有网格格宽必须相同，原点差必须是格宽的整数倍，
  否则拒绝（不做插值）。
- `data` 为非空、行长一致的矩阵，元素只能是有限数字或 `null`。
- `extent`：`intersection`（默认，空交集拒绝）或 `union`（最小包围矩形，
  网格覆盖之外按 `null` 处理）。

## 表达式

- 仅允许数字字面量、网格名称、括号与 `+ - * /`，支持一元负号（如 `-a`）。
- 唯一允许的调用是 `coalesce(e1, e2, ...)`（至少一个参数）：按顺序取首个
  非空值，命中后立即停止，后续分支不求值。
- 普通二元运算两侧都会求值；任一操作数为 `null`，结果为 `null`。
- 除零或结果非有限（如溢出）时结果为 `null`，该输出格坐标记入
  `error_cells`（`[列, 行]`，相对输出原点）。
- 属性访问（`a.b`）、下标（`a[0]`）、其他函数名等一律拒绝；
  表达式只被解析为内部 AST，不会作为代码执行。

## 结果格式

```json
{
  "x": 0, "y": -2, "cell": 2,
  "data": [[null, null], [0.1, null], [null, 2.0]],
  "stats": {"valid": 2, "null": 4, "min": 0.1, "max": 2.0, "mean": 1.05},
  "error_cells": [[0, 1]]
}
```

`stats` 统计输出中有效格数、空值数及有效值的最小/最大/均值；全为空时
min/max/mean 为 `null`。结果与输入网格在字典中的顺序无关。
